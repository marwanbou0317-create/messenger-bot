# بوت مسنجر للمجموعات

## الإعداد السريع

### 1. تثبيت الحزم
```bash
cd bot
npm install
```

### 2. إعداد الكوكيز (appstate)

**الطريقة الأولى - عبر أداة إعادة التعيين:**
```bash
node reset-cookies.js
```
ثم أدخل البريد الإلكتروني وكلمة المرور.

**الطريقة الثانية - يدوياً:**
- ضع ملف `appstate.json` الخاص بحساب الفيسبوك في مجلد `bot/`

### 3. تشغيل البوت
```bash
node index.js
```

---

## ملف config.json

| الخاصية | الوصف | الافتراضي |
|---|---|---|
| `prefix` | بادئة الأوامر | `/` |
| `botName` | اسم البوت | `Bot` |
| `superAdmins` | قائمة IDs السوبر أدمن | `["100079534109007"]` |
| `reconnectDelay` | وقت إعادة الاتصال (ms) | `5000` |
| `listenEvents` | الاستماع لأحداث المجموعة | `true` |
| `online` | إظهار البوت متصلاً | `true` |

## الأوامر

### أوامر عامة
| الأمر | الوصف |
|---|---|
| `/اوامر` | عرض قائمة الأوامر |
| `/سيرفر` | معلومات السيرفر والذاكرة |
| `/ابتيم` | وقت تشغيل البوت |

### أوامر المشرفين (Admin)
| الأمر | الوصف |
|---|---|
| `/محرك` | تشغيل/إيقاف المحرك |
| `/محرك رسالة [نص]` | تحديد رسالة المحرك |
| `/محرك وقت [ثواني]` | تحديد وقت الإرسال |
| `/محرك الذكي` | تفعيل/إيقاف الوضع الذكي |
| `/محرك حالة` | عرض حالة المحرك |
| `/قفل` | قفل/فتح هذه المجموعة |
| `/قفل الذكي` | قفل/فتح جميع المجموعات |
| `/قفل عادي` | قفل/فتح هذه المجموعة فقط |
| `/قفل حالة` | عرض حالة القفل |

### أوامر السوبر أدمن فقط
| الأمر | الوصف |
|---|---|
| `/رفع @شخص` أو `/رفع [ID]` | رفع شخص لمشرف |
| `/اخفاض @شخص` أو `/اخفاض [ID]` | إنزال شخص من مشرف |

## نظام الصلاحيات

- **👑 superadmin**: مطور البوت، محمي من الرفع والإنزال، له كل الصلاحيات
- **🔧 admin**: مشرف البوت، يمكنه استخدام المحرك والقفل (يُضاف في الذاكرة المؤقتة)
- **👤 user**: عضو عادي، يمكنه فقط استخدام الأوامر العامة

---

## المحرك

يرسل رسالة تلقائياً في مجموعة محددة:
- **عادي**: يرسل كل X ثانية باستمرار
- **الذكي**: يرسل فقط عند وجود نشاط (رسائل، تغيير الاسم، الكنيات...)

## القفل

يجعل البوت يتجاهل جميع الرسائل والأوامر من الأعضاء العاديين:
- **عادي**: في مجموعة محددة فقط
- **الذكي**: في جميع المجموعات دفعة واحدة
